# Generador Web de Currículum (CV)

Este proyecto es una página web para crear y exportar currículums.

## Archivos
- `index.html`: contiene la estructura HTML, los estilos CSS y el código JavaScript de la aplicación.
- `.gitignore`: excluye archivos temporales y configuraciones locales.

## Cómo ejecutar
1. Descarga o descomprime el proyecto.
2. Abre `index.html` en un navegador moderno (Chrome, Edge o Firefox).
3. Para utilizar todas las funciones, mantén conexión a Internet, ya que el proyecto carga bibliotecas externas mediante CDN:
   - Tailwind CSS
   - Google Fonts
   - Font Awesome
   - html2pdf.js
   - Mammoth.js

## Publicar en GitHub
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `README.md` y `.gitignore`.
3. Si deseas publicarlo con GitHub Pages, entra a **Settings > Pages**, selecciona la rama principal y la carpeta raíz (`/root`), y guarda.
